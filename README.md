# Economic-Growth-Dashboard
Developed an interactive Power BI dashboard to visualize and analyze economic growth, industry performance, and key price indicators through data-driven insights.

## Objectives

* Analyze economic growth trends over time.
* Compare industry-wise economic performance.
* Analyze Current Price vs. Constant Price.
* Identify key trends and performance patterns.
* Present insights through interactive data visualizations.

Project Insights

Economic performance varies across different time periods, highlighting changing growth patterns.
Different industries make different levels of contribution to overall economic performance.
Constant Price provides a better view of real economic growth, while Current Price reflects values affected by price changes.
Interactive visuals make it easier to identify trends, compare industries, and understand key economic indicators.

Final Conclusion

The project successfully transforms economic data into an interactive and meaningful Power BI visualization solution. The dashboard provides a clear overview of economic trends, industry performance, and price-based indicators, demonstrating how Data Analytics and Business Intelligence can support effective data-driven decision-making.
